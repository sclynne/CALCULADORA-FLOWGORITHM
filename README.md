## Sobre

Uma calculadora com 20 funções, projetada a partir de um fluxograma do Flowgorithm. O Sistema possui uma menu interativo oferecendo 20 funções matemáticas organizadas e estruturadas.

# Fluxograma

 - Alem do código,o projeto conta com um modelo visual feito no programa Flowgorithm para compreender o fluxo lógico das operações 

## Como rodar o arquivo 
 
 1. Faça o download do programa Flowgorithm;
 2. Baixe o arquivo nesse repositorio;
 3. Abra o Flowgorithm e abra o arquivo;
 4. Clique no botão run para iniciar o programa.
